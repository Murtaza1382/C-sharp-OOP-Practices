Object Oriented : It is a programming paradigm where we organize programs around objects.

Instead of thinking only:

"What functions should my program perform?"

OOP also asks:

"What things (objects) exist in my system, what data do they have, and what can they do?"

For example, in a banking system:

A BankAccount
A Customer
A Bank
A Transaction

Each of these can be represented as an object.


 -= Class : A class is a blueprint, template, or definition used to create objects.

======================> code in C# <=================

public class BankAccount
{
    // =========================================
    // 1. FIELDS / INSTANCE VARIABLES
    // =========================================

    private string accountNumber;
    private string ownerName;
    private decimal balance;


    // =========================================
    // 2. CONSTRUCTOR
    // =========================================

    public BankAccount(string accountNumber, string ownerName, decimal initialBalance)
    {
        this.accountNumber = accountNumber;
        this.ownerName = ownerName;
        balance = initialBalance;
    }


    // =========================================
    // 3. METHODS
    // =========================================

    public void Deposit(decimal amount)
    {
        if (amount > 0)
        {
            balance += amount;
            Console.WriteLine($"Deposited: {amount}");
        }
    }

    public void Withdraw(decimal amount)
    {
        if (amount > 0 && amount <= balance)
        {
            balance -= amount;
            Console.WriteLine($"Withdrawn: {amount}");
        }
        else
        {
            Console.WriteLine("Invalid withdrawal.");
        }
    }

    public void DisplayAccountInfo()
    {
        Console.WriteLine("----- BANK ACCOUNT -----");
        Console.WriteLine($"Account Number: {accountNumber}");
        Console.WriteLine($"Owner: {ownerName}");
        Console.WriteLine($"Balance: {balance}");
    }
}

 -= Constructor : A constructor is a special member used to initialize an object when it is created.
 
  -= Constructor Rules : The basic rules in C# and Java are !
        - Constructor name must match the class name.
        - A constructor has no return type.
        - It runs automatically when an object is created.
        - Constructors can have parameters.
        - Constructors can be overloaded

 -= Types of Constructors : The terminology can vary slightly between languages, but these are the most common types.
        - Default Constructor : A constructor with no parameters.
        ============> code in Java <========
            public BankAccount()
                    {
                        accountNumber = "UNKNOWN";
                        ownerName = "Unknown";
                        balance = 0;
                    }
                    BankAccount account = new BankAccount();
        - Parameterized Constructor : A constructor that receives parameters.
        ============> code . in Java <=============
            public BankAccount(
                        String accountNumber,
                        String ownerName,
                        double balance)
                    {
                        this.accountNumber = accountNumber;
                        this.ownerName = ownerName;
                        this.balance = balance;
                    }

                    BankAccount account = new BankAccount("ACC-001", "Murtaza", 1000);
        - Copy Constructor : A constructor that creates a new object using another object.
        public BankAccount(BankAccount other)
                    {
                        accountNumber = other.accountNumber;
                        ownerName = other.ownerName;
                        balance = other.balance;
                    }
                    BankAccount account1 =
                            new BankAccount("ACC-001", "Murtaza", 1000);

                        BankAccount account2 =
                            new BankAccount(account1);
        - Constructor Overloading : Constructor overloading means having multiple constructors in the same class with:
               . The same name (the class name)
               . Different parameters

 -= Static Variable : A static variable belongs to the class itself, not to individual objects.
 ==============> code in Java <==============
 public static int totalAccounts = 0;

  -= Advantages of Static Variables : 
        - Memory efficiency : Instead of creating the same value for every object, You can have one shared value.
        - Shared information : Example: public static String bankName = "Kabul Bank";
        - Global class-level information : Useful for:
            . Total number of objects
            . Company name
            . Configuration
            . Shared settings
            . Constants
-= Static Method : A static method belongs to the class, not to an object.
===================> code in Java <====================
public class BankAccount
{
    public static String bankName = "Kabul Bank";

    public static void displayBankName()
    {
        System.out.println(bankName);
    }
}
BankAccount.displayBankName();

 -= Restrictions of Static Methods : Because a static method belongs to the class, it doesn't automatically know which object you mean.
        - Static methods cannot directly access instance variables : 
        =================> code in Java <===============
        static void test()
                {
                    System.out.println(ownerName); // it gives error
                }
        - Static methods cannot directly call instance methods : 
        static void test()
                {
                    deposit(100); // gives error
                }
        - Static methods cannot use this : 
        static void test()
                {
                    System.out.println(this.ownerName);
                }

 -= Static Block : ⚠️ Static blocks exist in Java but not in the same form in C#. A static block is used to initialize static data.

 =======================> code in Java <==============
 public class BankAccount
{
    static String bankName;
    static int totalAccounts;

    static
    {
        bankName = "Kabul Bank";
        totalAccounts = 0;

        System.out.println("Bank system initialized!");
    }
}

Note  : The static block runs once, when the class is initialized by the JVM
